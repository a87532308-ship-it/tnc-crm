# UI 디자인 검수 기록

## 프레임 목업 전체 검수

UI 의사결정 전 단계에서 전체 화면의 정보 구조, 화면 이동, 상태별 정보 우선순위를 검수한다. 색상·아이콘·세부 컴포넌트 정책은 다음 단계에서 확정한다.

## 확정된 UI·테마 기준

- 모든 UI 의사결정은 A안: 여유형 카드, 명시적 저장, 복잡 입력 전체 화면, 화면당 핵심 행동 1개, 위험 중심 상태색, 맥락별 금액 단위
- 테마: 기존 브랜드 블루를 핵심 행동·강조 정보에만 중간 강도로 사용
- 분위기: 전문적, 단정하고 중립적
- 사용 환경: 이동 중 모바일 우선
- 서비스명: 굿모닝테라유림부동산 CRM

## 글래스모피즘 구현 전략 검수

- 방향: 전문성과 신뢰를 유지하는 절제형 글래스모피즘. 장식보다 업무 맥락의 구분에 사용한다.
- 적용: 앱 상단·하단의 고정 영역, KPI 묶음, 요약 카드의 배경.
- 제외: 입력폼, 표, 긴 상담 기록, 계약·청구의 금액 입력, 위험/오류 알림은 불투명 표면을 쓴다.
- 표면: `rgba(255,255,255,.74)`, 밝은 반투명 테두리, 18px 블러, 낮은 청색 그림자를 공통 토큰으로 사용한다.
- 가독성: 글래스 위 텍스트는 짧은 제목·요약·지표로 한정한다. 본문은 진한 잉크색, 위험 상태는 불투명 연한 빨강 배경과 빨강 텍스트를 유지한다.
- 성능: `backdrop-filter`는 큰 배경과 필요한 요약 카드에만 제한한다. 미지원 브라우저는 불투명 연한 배경으로 대체한다.

## 확정 · 전 화면 테마 적용

- 적용 강도: B 절제형.
- 화면 배경: 옅은 코발트 광원과 밝은 회백색 바탕.
- 글래스 적용: 고정 헤더, 전환·탐색 영역, 요약 KPI, 하단 메뉴.
- 불투명 적용: 영업 건, 계약·청구, 입력폼, 긴 텍스트, 위험 상태.

### 구현 화면

1. 오늘 할 일
2. 단계별 영업판
3. 영업 건 상세
4. 신규 영업 건 등록
5. 계약·청구
6. 성과
7. 회사 검색·이력
8. 관리

## 화면 1: 오늘 할 일

첫 검수 화면은 모바일 `오늘 할 일`이다. 목표는 사용자가 이메일 알림을 본 직후, 기한 초과·오늘 연락·신규 상담을 빠르게 판단해 영업 건을 열고 첫 행동을 시작하는 것이다.

### 포함 요소

1. 오늘 날짜와 내 담당/전체 전환
2. 첫 연락 KPI와 기한 초과 수
3. 우선순위 탭: 기한 초과, 오늘 연락, 신규, 이임, 견적 후 재연락
4. 카드별 회사명, 담당자, 마감 시각, 마지막 행동, 현재 상태, 고객 문의 한 줄 미리보기
5. 상태에 맞는 빠른 행동 대신 상세 화면으로 들어가는 안전한 흐름

### 이번 검수 범위

레이아웃과 정보 우선순위만 검수한다. 색상, 타이포그래피, 아이콘 체계, 실제 버튼 동작은 다음 UI 의사결정 단계에서 확정한다.
